## Feature 1 - Color coding

I absolutely love the color coding concept. Connecting the same parts by color makes it easy to follow and trace my work. When I create a tag such as user_name, the system will assign it a color. Any time I type user_name again, it will give it the same color as the original. This makes it every easy to spot and follow.

## Feature 2 – Auto Complete

The auto complete function is another favorite. The system offers built in codes to assit you in your code. On top of that, after you type in a string literal or variable, the system will show it as an option if you start typing the same beginning sequence. Example, if I use user_name, then the next time I start typing use... the program will provide a list of any matching variables for me to choose from. This is extremely helpful to help lessen silly spelling mistakes. I have a bad habit of capitalizing things and I found this to be a problem when typing my code. The auto complete function helps limit this.
